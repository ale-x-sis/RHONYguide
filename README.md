# RHONY Viewing Guide

A spoiler-light, mood-based viewing guide for *The Real Housewives of New York City*.

Built by Lex, for Lex — with just enough structure to help decide what to watch without turning Bravo into homework.

## What this is

This guide is a personal field guide for navigating RHONY episodes by:

* season
* episode importance
* enjoyment level
* NYC texture
* chaos agents
* cast context
* trip arcs
* essential catch-up value

The goal is not to recap every detail. The goal is to answer:

> What should I watch tonight, and do I actually need this episode to understand the larger RHONY arc?

## Main features

### Episode Guide

A season-by-season guide with quick scan data for each episode.

Each episode includes:

* **Essential / Optional** — whether the episode matters for canon, continuity, or future payoff
* **Good / Great / Elite** — how enjoyable or rewatchable the episode is
* **NYC apples** — a texture score for how New York the episode feels
* **Chaos Agents** — quick tags for the episode’s main energy
* **Synopsis / notes** — spoiler-light context for deciding whether to watch

### Pick My Episode

A small recommendation tool that asks a few mood-based questions and returns a viewing “prescription.”

It can recommend:

* one episode
* a short arc
* catch-up viewing before jumping ahead
* vacation chaos

### Who’s Who

A quick cast reference for remembering who is in which era and what role they play in the RHONY ecosystem.

### Trips Index

A guide to travel episodes and multi-episode trip arcs, because vacation chaos is its own genre.

## Why I made this

I started building this while watching later RHONY seasons and wanting a better way to decide when to skip, when to commit, and when an episode was “important” versus merely loud.

It became a low-stakes coding practice project and a small product/design exercise: a personal recommendation engine for a very specific viewing problem.

## Tech

This is a simple static site built with:

* HTML
* CSS
* JavaScript
* Netlify hosting

No framework, no database, no login. Just vibes, data, and a suspicious amount of Housewives taxonomy.
